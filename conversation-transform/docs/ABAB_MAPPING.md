# ABAB Mapping Notes

## Purpose

This document maps the experimental conversational workflow to concepts already defined in the ABAB Movie & TV Dialogue Annotation Guidelines.

The intention is:

- avoid inventing parallel standards
- preserve compatibility with existing annotation workflows
- reuse existing taxonomy and annotation logic whenever possible

---

## Current Principle

The guidelines document is considered the primary source of truth.

Experimental structures should adapt to the guidelines instead of creating incompatible schemas.

---

## Current Experimental Mapping

| Experimental Concept | ABAB / Annotation Concept |
|---|---|
| Conversation | Dialogue |
| Segment | Utterance |

| Timestamp | Temporal annotation |
| Code-switch insertion | Language annotation |
| Emotional escalation | Emotion annotation |

## Important Observation

The experimental objective is not humor extraction.

The relevant properties are:

- realistic timing
- natural interruptions
- escalation structure
- emotional dynamics
- authentic conversational repair
- natural speech disfluencies

---

## Current Approach

1. Use real conversational material.
2. Remove reveal/meta-radio sections.
3. Preserve natural dialogue structure.
4. Align annotations with ABAB conventions.
5. Only introduce minimal transformations when necessary.
